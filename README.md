# EntreHobbies - Plataforma Social de Eventos y Aficiones

**EntreHobbies** es una aplicaci&oacute;n web dise&ntilde;ada para conectar personas a trav&eacute;s de eventos relacionados con sus hobbies. La plataforma permite crear, buscar y unirse a actividades seg&uacute;n intereses comunes, facilitando la interacci&oacute;n social y el descubrimiento de nuevas aficiones. Este proyecto ha sido desarrollado como parte de un ciclo formativo, aplicando conocimientos de desarrollo web, bases de datos y dise&ntilde;o de interfaces.

## Fases del Proyecto

### **Fase 1: An&aacute;lisis de Requisitos**📋
En esta primera etapa se definieron los objetivos funcionales y no funcionales de la aplicaci&oacute;n. Se identificaron los perfiles de usuario (colaborador y administrador), las categor&iacute;as de eventos, subcategor&iacute;as y las funcionalidades clave como b&uacute;squeda, filtros, inscripci&oacute;n y gesti&oacute;n de eventos.

### **Fase 2: Dise&ntilde;o y Estructura del Proyecto**🧱
Se dise&ntilde;&oacute; la arquitectura de la aplicaci&oacute;n usando el patr&oacute;n MVC. Se estructuraron los m&oacute;dulos principales y se crearon los wireframes de las vistas principales en JSP. Esta fase incluy&oacute; tambi&eacute;n la planificaci&oacute;n de la base de datos y relaciones entre tablas.

### **Fase 3: Desarrollo Backend y Base de Datos**⚙️
Durante esta fase se desarrollaron los controladores en Java, la conexi&oacute;n con MySQL, y se implementaron los CRUDs para eventos y usuarios. Se configuraron rutas din&aacute;micas y se integraron formularios con validaciones b&aacute;sicas.

### **Fase 4: Desarrollo Frontend y Funcionalidades Interactivas**🎨
Se implementaron las vistas en JSP con Bootstrap, se a&ntilde;adieron filtros din&aacute;micos, buscadores por texto, y componentes interactivos mediante JavaScript (por ejemplo, actualizaci&oacute;n din&aacute;mica de eventos seg&uacute;n filtros o b&uacute;squeda). Tambi&eacute;n se aplic&oacute; l&oacute;gica condicional seg&uacute;n el rol del usuario.

### **Fase 5: Pruebas, Ajustes y Documentaci&oacute;n**🧪
Se realizaron pruebas funcionales en diferentes escenarios, se ajustaron errores y se mejor&oacute; la experiencia de usuario. Adem&aacute;s, se document&oacute; el c&oacute;digo y se redact&oacute; el resumen t&eacute;cnico, incluyendo funcionalidades destacadas como el buscador inteligente, los filtros din&aacute;micos y la distinci&oacute;n por rol.

## Tecnolog&iacute;as Utilizadas🧰

- **Frontend**: JSP, HTML, CSS, Bootstrap, JavaScript  
- **Backend**: Java (Servlets)  
- **Base de Datos**: MySQL  
- **Entorno de Desarrollo**: IntelliJ IDEA, Apache Tomcat
